1. Unzip this file.
2. Create a PUBLIC GitHub repository named yourusername.github.io
3. Upload these files directly into the repo root:
   - index.html
   - .nojekyll
4. In GitHub: Settings > Pages
5. Under Build and deployment:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
6. Save.
7. Wait a minute, then open:
   https://yourusername.github.io
